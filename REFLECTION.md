## 3. Bedömning och att dela publikt

*Uppgiften bedöms inte på kodens stil eller kvalitet, bara på en komplett inlämning. Påverkade det hur du arbetade? Och hur kändes det att posta din skärmdump/video publikt i Zulip, utan möjlighet att göra det privat?*

Svar: Kanske någorlunda, man försöker komma ihåg grunderna hur man ska skriva koden (stil och kvalitet) medans kan försökte få ihop något enkelt som var begripligt för en själv. Dock desto mer man höll på med koden så försökte fokus endast läggas på att förenkla och följa instruktionerna (keep it simple). Jag som är nybörjare och med en sommar endast för återhämtning och som startade igång min programmeringshjärna förra veckan i samband med kursintrot, så känns det något pinsamt kanske då andra skärmdumpar/videos se mycket mer komplexa ut än vad min gjorde..

## 4. Ditt program

*Vilket programmeringsspråk valde du, och varför just det?*

Svar: JavaScript. Stod mellan JavaScript eller Java, men känner mig något tryggare med JavaScript då vi arbetade mer med det under år 1, likväl som att det är något mer förlåtande än Java (mindre komplicerat).

*Vad gjorde du för att göra välkomstmeddelandet till något mer än bara `"Hej " + namn`?*

Svar: Det är i stort endast ett välkomstmeddelande. Endast en fråga vad man heter och därefter ett välkomstmeddelande + namn inklusive en ASCII-ram. Som sagt väldigt förenklat, mest för att försöka hålla det enkelt och komma in i grunderna igen efter det långa sommaruppehållet.

## 5. AI-samarbete

*Samarbetade du med någon AI-assistent (t.ex. ChatGPT, GitHub Copilot, Claude) — som en kollega snarare än bara ett verktyg? Beskriv kort hur, och ge gärna ett exempel på en prompt som gav ett bra resultat.*

Svar: Ja, jag har tagit hjälp av Google Gemini. Främst för att få en simpel idé som var lätt förståelig och som jag sedan kunde skriva om till mer begrilig kod som vi lärt oss från år 1. T.ex. att jag gick ifrån require (CommonJS) till import (ES-moduler) istället (vet från tidigare år 1 att vi använt oss av import men ville då även dubbelkolla med Gemini och frågade vilken standard som är bäst idag och fick då svaret import istället för require som ett försäkrande), samt att jag fick bra rekomendation från Gemini att använda readline-modulen i Node.js för laborationens ändamål/krav, vilket sparar tid och blir mer effektivt och pålitligt då det är en inbyggd standard.
